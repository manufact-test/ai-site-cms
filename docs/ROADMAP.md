# План разработки полной CMS — без MVP

**Принцип:** этапы ниже — **внутренние инженерные этапы**, не отдельные рыночные релизы. Запуск CMS только после выполнения **всех 135 обязательных требований** и интеграционной приёмки. 42 желательных функции планируются после оценки, 16 «Не нужно» исключены.

| № | Этап | Основной результат | Приёмка этапа |
|---|---|---|---|
| 0 | Документация и границы | MASTER ТЗ, ответы 1–193, договорённости, изоляция от CELIKOM | Владелец принимает ТЗ и исправленные зависимости |
| 1 | Выбор базовой архитектуры | Runtime, shared hosting, data-model, лицензии библиотек, адаптеры | Три типа сайтов проверены концептуально/PoC, выбор обоснован |
| 2 | Контракт ИИ | schema/manifest, валидатор, stable IDs, scope responsive, rules | Тестируются автоматические генерация и изменение блоков |
| 3 | CMS Core и модель версий | Хранилище, пользователи, страницы, data binding, черновик/публикация, история | Надёжное восстановление и изоляция данных |
| 4 | Лёгкий блоковый редактор | Страницы, список секций, изолированный live preview, дерево, клик, правые настройки | Открывается только выбранная секция, есть Undo |
| 5 | Полное покрытие свойств | Типографика, геометрия, фон, медиа, анимация, интерактивность, адаптив | Все обязательные пункты №1–100, №119 покрыты тестами |
| 6 | Страницы, компоненты, SEO | Shared секции, repeaters, страницы, SEO/OG/Schema/robots/sitemap/redirect | Приёмка №138–155, без создания страниц руками |
| 7 | Публикация и защита | Auth, history, concurrent edits, backup/restore, rollback, logs | Подтверждены обязательные №156–173 |
| 8 | Интеграция со стеками | HTML/CSS/JS, PHP, React/Next (static и SSR где доступно), shared hosting | Обязательные №174–193 проходят реальными сценариями |
| 9 | Надёжные обновления | Миграции манифестов, сохранение overrides, обновление CMS, откат | Никаких тихих потерь настроек и конфликтов |
| 10 | Полный регресс и аудит | Каждое «Обязательно» имеет независимую проверку; нагрузка, доступность, угрозы | 135/135 закрыто, нет критических дефектов |
| 11 | Первый полный релиз | Релизные файлы, инструкции, стандарт новой установки, backup/rollback | Владелец официально утверждает законченную CMS |
| 12 | Отдельный пилот CELIKOM | Тестовая интеграция конкретного сайта после полного релиза | Откат, безопасность, отсутствие поломок; отдельное согласование |

### Правила исполнения

- Никакого внедрения частей CMS в продакшен CELIKOM раньше этапа 11.
- Каждый принятый компонент покрывается тестами; нельзя объявить этап 10/релиз при незакрытом обязательном требовании.
- Неизвестные параметры — вопросы, не повод молча выбирать самую сложную реализацию.
- Архитектура документируется по фактическим решениям, принятым владельцем; рядом хранить reasons/trade-offs.
- Сравнение готовых open-source проектов проводить **после** утверждения требований и архитектурных ограничений.
