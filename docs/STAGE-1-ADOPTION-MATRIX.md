# AI Site CMS — Stage 1 decision applicability matrix for 135 required IDs (v1.30)

**Дата:** 18.10.2026 · **Статус:** план переиспользования, **не** функциональная приёмка CMS · **Исходник:** [requirements.csv](../requirements/requirements.csv) · [существующие ограниченные исследовательские свидетельства](STAGE-1-MANDATORY-EVIDENCE-MATRIX.md).

## Точная семантика — не путать с готовностью продукта

- **А = адаптируем внешнюю функциональность**: у кандидата есть относящийся к задаче готовый upstream-компонент / схема / поле / backend widget, однако контракт AI Site CMS, привязки, сохранение, безопасность и тесты всё равно пишем и проверяем.
- **С = создаём необходимую доменную функцию сами**: upstream-проекты в данной архитектуре не предоставляют достаточно прямой пригодной функции. Можно пользоваться вспомогательными библиотеками, но сам модуль уникальный.
- **Г = требование целиком готово**: в этой матрице **0**. Ни одна готовая система не удовлетворяет сразу всей формулировке соответствующего обязательного ID с нашим контрактом, рендерингом и проверкой.
- **Х = несовместимо**: для 135 ID выбранных трёх *составных* архитектур **0**. «С» не означает техническую невозможность; готовая **монолитная CMS** или Node-only runtime могут быть непригодны как *единая* основа. Таблица не утверждает, будто всё можно получить из коробки.
- **НИ ОДИН ID НЕ ПРИНЯТ** (0/135 product). R/D/N в [evidence matrix](STAGE-1-MANDATORY-EVIDENCE-MATRIX.md) — иная независимая ось: 43 частичных сигнала, 92 без целевого доказательства. Эти исследовательские эксперименты не превращаются в признаки Г или реализации.
- **A** = Jedison 1.27.1 + Slim 4 + Opis JSON Schema 2.6; **B** = RJSF 6.11 + Slim 4 + Opis; **C** = Winter CMS 1.2 + Jedison + Opis (условно пригодный тяжёлый PHP-вариант). **Все три — предложения, ничего не утверждено.**
- Это **экспертная классификация доступности переиспользуемых частей**, а не автоматически доказанная пригодность upstream для каждого пункта. Взаимодействие с конкретной библиотекой для данного ID не обязательно было запущено. Близкие к полям пункты получают А, но не «готово».

Для A/B одинаковые числа не означают одинаковую цену или производительность: RJSF React экосистема богаче, но в реальном тестовом bundle существенно больше.
