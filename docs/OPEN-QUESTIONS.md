## Важные внешние решения до написания кода

1. Runtime CMS и поддержка трёх классов сайта (статический, PHP, React/Next.js).
2. Public schema и API адаптера.
3. Модель обновлений и версионности.
4. Безопасность медиа и типизированных свойств.
5. Способ создания бэкапов и тест восстановления.
6. Где хранить опубликованную конфигурацию, чтобы публичный сайт не зависел от live CMS API.
7. Конкретные допустимые лицензии third-party решений и план самостоятельного распространения CMS.

**Важно:** никакие замечания аудита пока не заменяют ответ владельца в `REQUIREMENTS.md`.


## Исследовательская пометка checkpoint v1.11 — вопросы не закрыты (17.10.2026)
