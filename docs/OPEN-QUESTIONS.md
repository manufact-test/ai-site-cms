## Важные внешние решения до написания кода

1. Runtime CMS и поддержка трёх классов сайта (статический, PHP, React/Next.js).
2. Public schema и API адаптера.
3. Модель обновлений и версионности.
4. Безопасность медиа и типизированных свойств.
5. Способ создания бэкапов и тест восстановления.
6. Где хранить опубликованную конфигурацию, чтобы публичный сайт не зависел от live CMS API.
7. Конкретные допустимые лицензии third-party решений и план самостоятельного распространения CMS.

**Важно:** никакие замечания аудита пока не заменяют ответ владельца в `REQUIREMENTS.md`.


## Исследовательская пометка checkpoint v1.11 — вопросы не закрыты (17.10.2026)

Для Q02 и всех вопросов о бэкапах/rollback появились дополнительные **исследовательские доказательства**, но не принято окончательное решение: в [GitHub Actions #39059714864](https://github.com/manufact-test/ai-site-cms/actions/runs/39059714864) стенд PHP 8.3.6/Opis 2.6.0 с одним файлом last-known-good восстанавливал публичную страницу при повреждении current и делал явный rollback из сохранённой истории; при повреждении обеих копий получен 503. **Не закрывает Q02:** offsite резервирование, реальные механизмы восстановления на текущем shared-hosting, права, аутентификация и согласованная политика удержания ревизий требуют отдельного решения. [Подробный отчёт](STAGE-1-SNAPSHOT-PUBLISH-RESEARCH.md). Не менять статус «Открыто» до согласования с владельцем.
