## Что разрабатываем

Не ручной конструктор сайтов. ИИ пишет уникальный код секций и обязуется подготовить machine-readable описание структуры, всех используемых редактируемых свойств, их дефолтов, responsive значений, стабильных ID, действий и зависимостей. Если клиент сказал «сделай как хочешь» — **полная схема управления всё равно обязательна** (№119).

Пользователь открывает **одну секцию**, видит предпросмотр слева, параметры справа, выбирает элемент кликом либо в дереве, правит реальные параметры без программирования. Неиспользуемые свойства в настройках отсутствуют. Настройки сохраняются при обновлении кода, возможные конфликты обнаруживаются, есть история/публикация/откат. Публичный сайт не зависит от редактора.

**Поддерживаемые сайты:** HTML/CSS/JS, PHP, React/Next.js. CMS работает на обычном виртуальном хостинге, но сайт с Next SSR может требовать Node; Next static export допускается. Отдельная CMS-инсталляция и данные на каждый сайт. Нет WordPress-интеграции, универсального импорта уже готовых сторонних сайтов, редактирования произвольного CSS или создания страниц внутри админки.
