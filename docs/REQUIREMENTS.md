> «Обязательно» — нужно к первому полноценному публичному релизу CMS (не существует отдельного релиза MVP). «Желательно» — дополнительная возможность после/при реализации при наличии ресурсов; не может блокировать приёмку обязательного набора. «Не нужно» — не строим специально, если это не неизбежная внутренняя мера безопасной работы.

## Правило динамического интерфейса

Поддерживаемый движком тип параметра **не показывается** для страницы или компонента, если созданный ИИ сайт его не использует; доступные панели строятся из верифицированного манифеста компонентов. Исключения — необходимые базовые свойства и системные операции.
