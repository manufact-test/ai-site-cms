## 4. Архитектурное ограничение и реальная следующая задача

Существующая кнопка Studio **«Подключить готовый сайт»** принимает `manufact-approved-site-handoff-v1/v2` с typed `manufact-ai-site-v1` contract, зарегистрированными компонентами/Design Graph и обязательным доказательством трёх согласованных прототипов. Она **НЕ импортирует произвольный HTML/CSS/JS ZIP**. Правила: [stage3/docs/APPROVED-SITE-PACKAGE.md](../stage3/docs/APPROVED-SITE-PACKAGE.md) и MASTER ТЗ §1–2. Не обходить валидацию созданием фиктивного `approved` пакета и не превращать исходный HTML в обезличенный набор карточек.

**Следующий большой сквозной инженерный блок:** разработать **узко ограниченный, проверяемый owner-controlled source-preserving adapter для данного CELIKOM** (не универсальный HTML importer) так, чтобы существующий Studio мог редактировать разрешённые 99 текстовых ключей **при сохранении авторского HTML/CSS/JS** и показывать оригинальный визуальный сайт; отдельно определить безопасность исполнения исходного JS, хранение источника/ассетов, модель редактирования, предварительный просмотр, версии, Save/Publish/Restore и возврат без потерь. Сначала аудит реальной пригодности архитектуры и защита от небезопасного выполнения кода; только затем реализовать один сквозной сценарий. Если текущий CMS renderer несовместим с preservation, честно показать ограничение и варианты прежде, чем ломать CMS ядро.

Тестовые критерии: сначала локально проверить точную визуальную копию, затем добавить **один** безопасный сайт в изолированной среде, открыть в существующем Studio, изменить заголовок и вопрос FAQ, Save → reload → Preview → Publish → Restore, сравнить исходный CSS/JS/HTML и скриншоты 1440/768/390; аудио и Manrope проверять **только после восстановления оригинальных легальных ресурсов**. FOX/production/действующую БД не трогать без отдельной авторизации владельца.

## 5. Запреты и переход

- **Никаких новых дизайнов, генерации картинок, упрощения до шаблона, фальшивых функций CELIKOM, второго Studio, общесистемного «импорта чужих сайтов».**
- **Не менять `main`, production CELIKOM, FOX, исходную базу или публичный сайт.** Пользователь заранее не санкционировал деплой; черновой PR #11 не merge.
- Для браузера/Hostinger есть **существующий отдельный Work**: Lead при необходимости передаёт пользователю короткую готовую задачу для Work; не предлагать плагины.
- Документацию обновлять по просьбе о следующем переходе, не во время каждого `продолжаем`; следующий заход должен быть одним цельным реальным инженеринговым блоком.
- Старый [FIRST-SITE-CELIKOM-DESIGN-NOGO-2026-11-08.md](FIRST-SITE-CELIKOM-DESIGN-NOGO-2026-11-08.md) и A–F дизайнерский план остаются **историческими** для этого первого пилота после решения владельца. Они **не означают**, что в целом CMS разрешено импортировать чужие сайты без контроля.
