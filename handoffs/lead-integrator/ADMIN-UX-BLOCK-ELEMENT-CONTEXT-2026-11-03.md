## Owner-facing outcome

The single existing Stage3 Studio Inspector now has two explicit contexts:

1. **Block** is selected automatically when navigating to a page or clicking a section in the structure. The panel shows the selected block identity, device visibility, form configuration / field-step builder when relevant, and the advanced shared-section controls. Individual field properties are not shown in this context.
2. **Element** is selected via the Inspector switcher, then from the element/repeater list. It shows the selected field/question title and only that element's editable properties. Repeat-card/FAQ item operations stay under each item's single disclosure menu. Whole-block operations are not mixed into the element field list.
3. Media binding, audit issue focus and visual-review focus explicitly restore element context. The switching preference is local UI state; it does not change site.json, typed manifests or storage.

New `#inspector-scopes` buttons use pressed states and keyboard-focus styling. The Inspector group label follows the active context. Offline dark and hosted light modes have matching CSS. The old DOM controls, `D.edit`, `D.structure`, `D.inheritBreakpoint`, Undo/Redo, Save/Review/Publish, auth and PHP authority remain in place.
