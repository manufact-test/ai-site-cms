- `stage3/sdk/contract.cjs`, `draft.cjs`: `manufact-ai-component-v1` и `manufact-ai-site-v1`, декларативный реестр first-party components, строгие стабильные ID, `content/style/behavior` typed fields, desktop/tablet/mobile fallback, отказ unknown/unsafe input, сохранение owner edits при manifest upgrades; immutable draft, CAS edits, Undo/Redo, diff, local no-design scaffold, JSON import/export.
- `stage3/studio/`: самостоятельная офлайн Studio ZIP, responsive block preview с CSP, страница/секция/элемент/поля, локальная история; server-hosted Studio на `/studio`, login/logout, site switch, explicit server Save и отдельный Publish; server revisions и restore, страницы/секции, движение/удаление и owner-editable media/gallery.
- `stage3/server/`: изолированные PHP 8.3 API с session, CSRF, auth, origin policy; `SiteRepository` на disposable SQLite + реализация PDO MySQL **без реального MySQL интеграционного теста**. Tables: users, drafts, revisions, publications, publication_history, media, submissions, notifications, section_templates. Snapshot publication separates saved draft and public release; server renders registered sections and generates standalone HTML release via `server/bin/export-published.php`.
- Media first-party storage PNG/JPEG/WebP up to 450 KB, image showcase and immutable copy in static exports.
- Old `lead-form` and new `lead-form-flex` with 3 configurable slots (text/tel/select/textarea), consent, honeypot, rate limit, revision-HMAC, input validation; separate collector-only public root; private submissions and unread in-CMS notices. **No real email/Telegram notification sending**, only in-app. Static form requires explicit collector origin; public HTML alone cannot receive submissions.
- **Последний большой блок (v1.57)**: `draft.structure` supports `duplicatePage`, `duplicateSection`, `applyTemplate`. Fresh globally unique page, section and element IDs; retained values/owner overrides, reject duplicate page paths and unregistered manifest. Hosted Studio has commands «Копировать страницу/блок», site-scoped **durable section templates** (save existing selected section, list, insert, remove); form field and media values maintained, new insertion is local draft with Undo/Redo, explicit server Save and separate Publish. `SiteRepository` stores validated snapshots by site; API `GET/POST /api/sites/{siteId}/templates`, `POST /api/sites/{siteId}/templates/{templateId}/delete`, authenticated and CSRF-protected for writes. 60 templates/site limit; **no cross-site preset sharing yet**. Old pages and published releases are unaffected.
