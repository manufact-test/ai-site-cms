## Новый крупный функциональный блок
В cms/stage2-preview/ продолжена безопасная локальная работа с изображениями: прямые кнопки Фото на hero, story, карточках каталога/услуг; выбор из локальной медиабиблиотеки и загрузка JPG/PNG/WebP с WebP-оптимизацией; единое описание ALT; фокус кадра X/Y 0–100 через клик, ползунки и пресеты; Undo/Redo, сохранение и JSON/ZIP roundtrip. Позиция и ALT общие для одного фото во всех применениях. Новые поля необязательны в старом v10 JSON (центр 50/50), лишние/некорректные ключи отвергаются.
Найдена структурная проблема старого iframe: CSP оболочки блокировал встроенный CSS даже при дочернем unsafe-inline. Parent CSP теперь допускает только локальный style-src blob:, без разрешения inline styles; скрипт-свободный srcdoc получает CSS через одноразовый Blob stylesheet. Самодостаточный HTML экспорт сохраняет встроенный CSS без HTTP и служебных кнопок. Повторная подписка на iframe events устранена.
Это всё исключительно Stage2 OFFLINE UX preview, НЕ AI site generation и НЕ production auth/CMS/API/MySQL/deployment/publish.
