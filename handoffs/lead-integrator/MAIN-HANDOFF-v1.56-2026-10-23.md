После большого блока — ОДИН необходимый реальный browser smoke/E2E и существующий CI; не отключать security checks. Следующее сообщение «продолжаем» означает готовность продолжить самостоятельно, **не повторять те же вопросы**. Перед сменой чата обновлять документы только по прямой просьбе владельца, что сейчас и сделано. ## 3. Что точно есть в Stage3 — не обещание, а код

**SDK `stage3/sdk/contract.cjs` + `draft.cjs`:** версионированный `manufact-ai-site-v1` и компонентный манифест; строгие/замкнутые поля `content.*`, `style.*`, `behavior.*`; стабильные IDs; responsive desktop/tablet/mobile; типизированные редакторы только для используемых параметров; регистрация нестандартных декларативных компонентов, безопасный media reference, no-design двухстраничный сайт без AI-провайдера; план миграции манифеста с сохранением ручных правок и явными конфликтами, immutable draft, редактирование с `expectedRevision`, Undo/Redo, data-only blockPreview.

**Рабочая локальная Studio `stage3/studio/index.html`:** 3 колонки, навигация страницами/блоками, конкретный изолированный блок в sandbox iframe, выбор элемента и auto-generated правые поля, desktop/tablet/mobile, немедленный preview без активного скрипта/сетевых вызовов, Undo/Redo, **явная кнопка «Сохранить черновик»**, максимум 12 локальных версий/восстановление, импорт и экспорт JSON, новый сайт без макета. CSS только для предпросмотра; `srcdoc` inert, экранирование содержимого. Сайт не публикуется, нет рабочего HTTP API, реальной БД и AI-генератора.
