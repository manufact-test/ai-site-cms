## 2. Что функционально сделано после v1.50

Офлайн лаборатория `cms/stage2-preview/` перешла от технической одно-страничной макетной панели к более связному демонстратору:

1. **Визуальный UX:** переработанная оболочка с отдельной структурой сайта, холстом/инспектором, обзором проекта, карточками страниц и SEO замечаниями, деревом страниц, поиском секций, полноэкранным режимом и выбором секции кликом внутри изолированного iframe.
2. **Страницы/контент:** три многостраничных стартовых набора; 11 редактируемых секций; изменение порядка/создание/дублирование страниц; копирование блоков между страницами; редактирование SEO title/description, меню; локальные версии/undo/redo; заметки с выгрузкой Markdown.
3. **НОВОЕ v1.51 — единые site settings:** подпись у названия, подвал, глобальное меню, возможность скрыть отдельную страницу из меню (не удаляя её из проекта), обратимое скрытие секций (сохранение содержимого/идентификаторов). Нельзя скрыть последнюю видимую секцию; главная страница остаётся в меню.
4. **Согласованный site export:** скачивается автономный ZIP HTML страниц с рабочей навигацией; скрытые из меню страницы сохраняют HTML-файл, скрытые секции не появляются в HTML, но все данные остаются в `project-backup.json`. Настройки экранируются и применяются в iframe и статическом экспорте.
5. **Совместимость:** локальный строго валидируемый формат `ai-site-cms-stage2-multipage-preview-v3`; старые v2 JSON проекты/сохранения и legacy single-page JSON преобразуются в v3. Эти схемы **не** являются контрактом настоящей Stage3 CMS.
6. **Один критический user-path Chromium smoke** проверяет также v3 миграцию, скрытия, ZIP, офлайн owner kit, заметки, безопасность/zero HTTP calls; существующие системные PHP/security CI сохранены без отключений.

## 4. Практика следующего чата

- Сначала сверить настоящий GitHub `main`, docs/NEXT-CHAT последний §56, status, workflow и этот handoff.
- Одна команда `продолжаем` — **целый большой связанный функциональный блок**, не отдельный фикс и не «ещё 10 тестов». Продолжать внутри задачи после первого коммита/успеха, пока не выполнен полезный законченный объём.

- По обычным `продолжаем` не пересохранять docs. Следующее обновление handoff и `PROJECT-STATUS` только по явному запросу при переходе чата.
