**Последний большой заход:** создали **Crawl Repair Planner**. Это новый рабочий модуль `lib/crawl-repair-planner.cjs` + `lib/crawl-repair-view.cjs` + `bin/prepare-crawl-repair.cjs`. Он сверяет утверждённый Blueprint с операторским снимком Site v1, оригинальными robots и sitemap и **создаёт два готовых для изучения, но НЕ для непосредственной публикации файла**: `PROPOSED-robots.txt` и `PROPOSED-sitemap.xml`. Генерирует только канонические индексируемые URL без вымышленных lastmod. По явно выбранным page ID может точечно предложить `Allow: /path/$` внутри уже существующей изолированной группы Googlebot/Bingbot. Общие, неоднозначные, wildcard-группы, noindex и расхождение Site v1↔Blueprint переводит в ручной контроль либо отказывает. Перезапускает существующий анализ robots/sitemap и даёт HTML/JSON/Markdown-отчёт, список рисков и SHA256. **Это не CMS-публикатор и не автоматическая правка продакшена.**

Предыдущий заход до него добавил `review-crawl-policy.cjs`, `compare-crawl-policy.cjs` и `correlate-crawl-indexing.cjs`: анализ Googlebot/Bingbot, регрессии до/после изменения правил, и осторожное сопоставление с операторской выгрузкой индексации GSC. Никакой причинности/фактической индексации Google по этим файлам не доказываем.
