# AI Site CMS — интерактивный продуктовый предпросмотр (Stage 2)

Это **локальная демонстрация будущего UX CMS**, не production-админка и не начало Stage 3. Её цель — как можно раньше смотреть и править **страницу в браузере**, а не строить новые тестовые контуры до появления продукта.

## Как запустить на своём компьютере (Windows / macOS / Linux)

1. Скачайте исходники репозитория (Code → Download ZIP) и распакуйте.
2. Нужен **Node.js 22+** для однократной сборки уже выбранного Jedison.
3. В терминале откройте cms/editor и запустите npm ci, затем npm run build.
4. Откройте **cms/stage2-preview/index.html** двойным щелчком в Chrome/Edge.

Сама демонстрация после сборки работает **офлайн**, без PHP, MySQL, сервера и подключения к Hostinger. Node не требуется во время просмотра. В GitHub Actions есть снимки интерфейса десктоп/мобильной версии; они содержат только вымышленные примеры и не распространяют исполняемые зависимости.

## Что реально работает

- Выбор одной из **шести секций**: главный экран, преимущества, о компании, отзыв, FAQ, контакты/CTA.
- Поля на базе настоящего **Jedison 1.27.1**, редактирование с обновлением страницы прямо в изолированном iframe.
- Добавить, дублировать, удалить и переместить секции, переключить одну из трёх оформленных тем.
- Десктопный и мобильный предпросмотр, редактирование названия проекта.
- **Экспорт JSON** в файл, **импорт JSON** обратно в браузер с проверкой набора секций и типов. Нет сетевых запросов, сохранения на сервере или браузерного постоянного хранилища.
- Ограниченный фиксированный набор свойств, экранирование текста и отключённые скрипты/формы в предпросмотре. Настоящие формы не отправляют данные.

## Что это **не** делает

Никакой авторизации, ролей, серверной БД, черновиков, публикации, загрузок медиа, генерации сайта ИИ или обновления посетительского сайта. Контактная кнопка — только демо. JSON — **не утверждённый контракт Stage3 и не полноценный бэкап**. Никакого автоматического размещения на Hostinger. Все эти функции разрабатываются отдельными продуктовыми этапами после приёмки Stage2. Реальный сайт посетителя и offweb Hostinger package этим демонстратором не меняются.

## Для разработчика

node editor/tests/stage2-preview-smoke.cjs запускает **один** сквозной Chromium smoke после сборки Jedison. Цель — доказать, что пользователь реально может изменить страницу, а не расширять бесконечный список микропроверок. CI делает два скриншота для продуктового просмотра.

**Рабочий принцип:** большие вертикальные продуктовые задачи → доступный просмотр → исправление по обратной связи → необходимая короткая проверка. Не использовать число тестов или коммитов как показатель прогресса.
