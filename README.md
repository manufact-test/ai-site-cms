# AI Site CMS

**Статус:** только документация; исходный код CMS ещё не разрабатывался.  
**Дата:** 17 октября 2026.

AI Site CMS — самостоятельная система детального управления сайтами, которые разрабатывает ИИ. Не визуальный конструктор страниц: ИИ создаёт дизайн, компоненты и манифесты редактируемых свойств, а владелец изменяет готовые блоки в изолированном редакторе (предпросмотр слева, настройки справа).

## Принятые решения

- 12 частей опросника, **193 требования**: **135 обязательно**, **42 желательно**, **16 не нужно**.
- **Никакого урезанного MVP:** первая полноценная версия считается готовой лишь после проверки всех 135 обязательных функций. Внутренние этапы разработки и тестовые сборки допустимы.
- Полная схема управления создаётся ИИ даже при отсутствии дизайн-ТЗ; новые настройки регистрируются автоматически, а неиспользуемые не показываются.
- Изменения владельца переживают обновления кода, выявляются конфликты, предусмотрены версии и откат.
- Обособленная установка/данные каждого сайта; поддержка HTML/CSS/JS, PHP, React/Next.js (с учётом ограничений инфраструктуры).
- Не разрабатываем WordPress-интеграцию, визуальную вёрстку страниц мышью, ручное редактирование CSS, универсальный импорт существующих сайтов.
- Код и репозиторий независимы от CELIKOM. После полного релиза CELIKOM можно протестировать отдельно, безопасно и с возможностью отката.
